Transport · 运输方式

海运 · 海卡 · 空运 · 空卡

每条线路稳定运营 15 年以上，一手货代、自有渠道、自家装柜，全程 DDP 双清包税到门。

海运 Sea
整柜 · 拼柜 · 超大件
整柜 20 / 40 / 40HQ 拿底舱价，拼柜灵活起运。家具、家电、囤货、超大件机械都能装 —— 一手装柜，自己排载。
  • 整柜 / 拼柜灵活选
  • 超大件 · 重货可装
  • 长期客户可锁价
海卡 Sea + Truck
海运到港 + 卡车到家
海运抵港后无缝衔接当地卡车，直接送到收件人门口。性价比高于纯空运，时效比纯海运更可控，适合家具大件、电商补货。
  • 港口提柜 · 自有车队
  • 派送到家 / 上楼可议
  • 无需收件人提货
空运 Air
急用 · 贵重 · 小批量
自有航空舱位，12 KG 起寄。化妆品、电子产品、礼物、补寄文件首选，旺季也能拿到舱位。
  • 12 KG 起寄
  • 敏感货特殊渠道
  • 急件 7–10 天到门
空卡 Air + Truck
空运清关 + 卡车送门
空运快线 + 目的国卡车派送，全程双清包税。比快递便宜、比海运快 —— 美西常用专线，留学行李 / 中型电商货首选。
  • 快线 + 末端派送
  • DDP 双清包税
  • 美 · 加 · 英 全境派

FAQ · 常见问题

老客户最常问的 23 个问题

从「能不能寄」到「怎么付款」，把你想问的都列出来了。还有问题？直接微信我。

01 能寄哪些国家？
中国到美国、英国、欧洲（德法荷比意西、北欧、含俄罗斯专线）、加拿大全境派送，DDP 双清包税到门。私人地址、FBA 仓、偏远地区都可以送。
02 从深圳到美国 / 英国 / 欧洲 / 加拿大要多久？
海运参考 25–45 天到门，空运参考 7–12 天到门。具体以当期航班、港口、清关状况为准，旺季（11–12 月及圣诞新年）会浮动 3–7 天。
03 冷冻食品、酒水、药品、品牌货可以寄吗？
可以。冷冻食品全程 -18°C 冷链；白酒、调料、火锅底料、酱油等液体走 DDP 渠道；化妆品、护肤品、香水可寄；中成药 / 保健品 / 处方药可寄；带 logo 的品牌正品也接。
04 怎么报价？
加微信 anitaleung8888，拍一张货物照片发过来，告诉我大致尺寸 / 重量 / 目的地城市，5 分钟内给你报价。报价透明，不藏后续费。
05 我在北京 / 上海 / 其他城市，可以寄到深圳仓库吗？
可以。全国任意城市都可以用快递（顺丰 / 京东 / 德邦）或货运寄到深圳坂田自营仓，到仓后我会在微信同步并安排出运。
06 DDP 双清包税到门是什么意思？
DDP（Delivered Duty Paid）= 双清（出口清关 + 进口清关）+ 包税（关税 / 增值税我承担）+ 到门（卡车送到收件人门口）。你只需要在家签收，全程不用再付任何费用。
07 走海运还是空运怎么选？
看时效和体积。家具 / 家电 / 囤货 / 超大件优先海运（25–45 天，性价比高）。急件 / 贵重 / 小批量优先空运（7–12 天）。中等批量电商货可选海卡或空卡折中。
08 最小起寄量是多少？
海运无最小起寄量（一两件家具也可以拼柜）。空运 12 KG 起寄。淘宝集运不限件数，零散小包都可以集中到仓后统一打包。
09 货物在路上能跟踪吗？
可以。出运后提供货运单号 / 提单号，全程进仓 → 在途 → 清关 → 派送四个节点，每个节点都会在微信告诉你，不用自己刷网站。
10 会不会丢件或被海关扣件？
我们走自有清关渠道，常规货物清关稳定，极少出现扣件。万一发生意外，第一时间在微信告诉你，并按实际情况赔付或重发，不甩锅。
11 可以寄家具到美国 / 英国 / 加拿大吗？
可以。沙发、床垫、红木家具、餐桌、衣柜都能寄，走海运整柜或拼柜最划算。海卡可以直接送到家门口，可议是否上楼。
12 亚马逊 FBA 头程可以做吗？
可以。FBA 美 / 英 / 德仓 DDP 头程是我们的主力业务，支持卡派 / 卡转 / 海运直送，提供入仓预约 + 贴标 + 申报。
13 淘宝集运怎么做？
把你的淘宝 / 拼多多 / 1688 收货地址填我家深圳仓库，多店铺包裹陆续到齐后统一打包出运。一次集运比多次单发省一大半运费。
14 留学行李怎么寄到英国 / 美国 / 加拿大？
留学专线常年稳定运营。书籍、衣物、被褥、电饭煲、调料都可以走，全程 DDP 包税，直接送到宿舍 / 公寓门口，不用你跑邮局取件。
15 锂电池 / 充电宝 / 磁性产品可以寄吗？
锂电池设备类（手机 / 电脑 / 充电宝）可以走特殊渠道，需要提前在微信告诉我型号 / 瓦时。纯锂电单独走有限制，磁性产品走专线申报。
16 化妆品、护肤品能寄美国 / 英国 / 欧洲吗？
可以。化妆品 / 护肤品 / 香水都接，走 DDP 渠道清关包税。液体类有特殊打包要求，发我微信我告诉你怎么寄最稳。
17 可以现场来仓库看吗？
欢迎。深圳市龙岗区坂田街道上雪科技园东区 8 号 F 栋 103，周一至周六 09:00–22:00 都在。来之前微信打个招呼，我接你进来看货怎么装、怎么打包。
18 怎么付款？
微信 / 支付宝 / 银行转账都可以。一般是货到仓库、装柜前付款，老客户可议预付 + 尾款。报价透明，没有任何后续加价。
19 货物需要打包吗？我自己打还是你们打？
小件可以自己打包寄到仓库。大件 / 易碎件 / 家具建议直接寄过来，我们仓库统一加固打包（木架 / 气泡膜 / 防潮膜），打包费按实际用料算，提前告知。
20 体积重和实重怎么算？
海运按体积 / 重量取大者计费，体积 = 长×宽×高（cm）/ 6000 折算成 KG。空运同理但因子是 / 5000 或 / 6000，因渠道而异。报价时我会一并算清。
21 收件人不在美国 / 英国本地，可以代签收吗？
可以。派送前会先电话 / 邮件预约时间。如果收件人当天不方便，可以指定邻居 / 物业代签，或改约时间。FBA 仓走预约入仓流程。
22 为什么不在网站上展示价格？
货代价格随路线、季节、货物属性、目的地远近浮动很大，固定价格表反而误导。我希望你看到的是真实可执行的报价 — 加微信发照片，5 分钟内拿到当下最准的价。
