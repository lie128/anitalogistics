加拿大清关 — CARM 时代怎么走

加拿大边境服务局（CBSA）的 CARM 系统于 2024 年全面启用，进口商需注册 RPP 账户。我们用自有加拿大清关代理（Customs Broker），代客户走 CBSA 申报，GST / HST / PST 由我们代收预付。

DDP 模式下所有税费都由我们承担。常规品类清关稳定，扣件率低；偶有抽查也会立即处理。

食品 / 农产品类需走 CFIA 申报；化妆品 / 护肤品走 Health Canada 备案；药品走专门通道。这些品类我们都跑过，客户不需要自己处理任何申报。

寄加拿大 · 常见问题

01 中国寄加拿大海运多久？
深圳到加拿大西部（温哥华）海运参考 25–30 天到门；深圳到加拿大东部（多伦多 / 蒙特利尔）参考 28–32 天到门。门到门含报关 + 清关 + 末端卡派。
02 中国寄加拿大包括 GST/HST 吗？
包。DDP 模式下 GST / HST / PST 全部由我们代收预付。收件人在加拿大签收即可，不需要再付任何税费。
03 CARM 新系统对中国寄加拿大有影响吗？
没有。CARM 是加拿大 CBSA 2024 全面启用的进口商账户系统。我们已对接 CARM，常规品类清关流程不受影响，客户也不需要自己注册。
04 加拿大留学生宿舍可以直送吗？
可以。UofT / UBC / McGill / Waterloo 等学校宿舍 / 学生公寓都送过，空卡 8–11 天到门，提供宿舍地址即可。
05 加拿大北部三省（NWT / YT / NU）可以送吗？
可以。北部三省走专线 / 偏远派送，时效略长（约 +3–5 天），有相应附加费用，报价时一并算清。
06 加拿大冷冻食品可以走吗？
可以。腊肠、速冻饺子、海鲜、肉类我们都走过 — 全程 -18°C 冷链 + CFIA 申报渠道，温哥华 / 多伦多 / 蒙特利尔都送到家。
07 能寄到 FBA Canada 仓库吗？
可以。YYZ4 / YVR4 等 FBA Canada 仓都走过，DDP 入仓（含 GST/HST），预约 + 贴标 + 申报全包。
