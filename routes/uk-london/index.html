为什么伦敦留学生 / 华人都找 Anita？

伦敦是英国线最大的目的城市，我们每周都有班次。海运经 Felixstowe（英国最大港）或 Southampton 进港，落地后自有卡车 1–2 天送 Zone 1–6 任意地址。开学季 UCL / LSE / Imperial / KCL / Goldsmiths 宿舍直送是稳定线 — 提供宿舍地址 + 房间号，到货前预约时间，签收即收。Soho 唐人街、Colindale、Croydon 的华人家庭和餐馆是另一大客户群，餐饮原料补货、化妆品 / 红酒进口、家具囤货都跑得多。脱欧后清关规则我们已完全跑通 — ≤£135 走 IOSS，>£135 标准进口报关，VAT 都由我们预付。

伦敦清关 — 脱欧后怎么走通

英国 2021 年脱欧后清关与欧盟脱钩。Felixstowe / Southampton 落地后由我们的 UK 清关行向 HMRC 报关，£135 以下走 IOSS（VAT 直接由发件方代缴），£135 以上常规进口报关 + VAT 预付。

DDP 模式下 VAT 和关税都由我们承担。收件人在 UCL 宿舍 / Soho 餐馆 / Colindale 家里签收，不需要再付任何费用 — 真正"到门不补单"。

化妆品需要 UKCA 备案；食品类（含中餐调料）走 CHED 申报；红酒需消费税专门通道。这些我们都跑通 — 客户不需要自己处理任何申报。

寄伦敦 · 常见问题

01 深圳到伦敦海运多久？
深圳到伦敦海运参考 30–35 天到门（整柜直挂 Felixstowe / SOU / LGW），拼柜 32–38 天。空运 7–10 天，Heathrow 直飞。
02 伦敦 UCL / LSE / Imperial 宿舍可以直送吗？
可以。提供宿舍地址 + 房间号 + 收件人姓名即可，空卡 8–11 天到门，宿舍前台 / 收件室签收。书籍、被褥、电饭煲、调料都接。
03 伦敦寄货含 VAT 吗？
包。DDP 模式下 VAT 和关税都由我们预付，£135 以下走 IOSS，£135 以上常规进口申报。在伦敦签收即可，不需要再付任何费用。
04 Soho 唐人街餐馆补货可以做吗？
可以。调料、干货、火锅底料、茶叶常温走 DDP；冷冻品类（饺子、海鲜）走 -18°C 冷链。Soho / Bayswater / Camden 餐馆都送过。
05 伦敦 FBA UK 仓库可以送吗？
可以。LBA4 / MAN1 / EUK5 / BHX4 等英国 FBA 仓都走过，DDP 入仓（含 VAT），预约 + 贴标 + 申报全包。
06 红酒 / 化妆品能寄伦敦吗？
可以。红酒走专门通道（含消费税）；化妆品需 UKCA 备案，常规品牌都跑过，DDP 含 VAT。
